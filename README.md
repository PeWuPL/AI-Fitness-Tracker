# SAMOZAMYKACZ — aplikacja do mierzenia aktywności fizycznej

Projekt laboratoryjny: responsywna (mobile first) aplikacja webowa do zapisywania aktywności fizycznej
i wyświetlania wykresów dla każdej formy ćwiczeń.

- Backend: PHP 8.2+, Symfony, API Platform, Doctrine ORM, PostgreSQL
- Frontend: Next.js (TypeScript)

Etap: dokumentacja i planowanie. Zobacz:
- `docs/SRS.md` — specyfikacja wymagań
- `docs/WBS.md` i `docs/estimates/` — podział prac i szacowanie (Delphi)
- `docs/OPEN_ISSUES.md` — otwarte kwestie
- `AGENTS.md` — kontekst i zasady dla agentów AI (Claude Code, Codex, Cursor itd.)
- `CLAUDE.md` — import `AGENTS.md` dla Claude Code
